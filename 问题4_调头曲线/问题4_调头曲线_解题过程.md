# 问题 4：最短调头曲线与调头全程运动

## 1. 题设与已固定的量

| 量 | 值 | 来源 |
|---|---|---|
| 盘入螺线螺距 | 1.7 m | 问题 4 给定 |
| 螺线系数 $b$ | $1.7/2\pi = 0.270563$ | $r=b\theta$ |
| 调头空间半径 | 4.5 m | 沿用问题 3 |
| 两弧半径比 | $R_1:R_2 = 2:1$ | 问题 4 给定 |
| 相切条件 | 弧1 切盘入螺线、弧2 切盘出螺线、两弧相切 | 问题 4 给定 |
| 龙头前把手速度 | 1 m/s | 问题 4 给定 |
| 板凳数 | 223（1 龙头 + 221 龙身 + 1 龙尾），把手 224 个 | 附件 |

盘出螺线与盘入螺线关于螺线中心呈中心对称，即 $Q(t) = -P(t)$。注意题目只说**两条螺线**中心对称，并未要求调头路径本身中心对称。

## 2. 坐标与行进方向约定

$$P(t) = b t(\cos t,\ \sin t),\qquad u(t) = -\frac{P'(t)}{|P'(t)|}$$

龙头沿 $t$ 减小方向盘入，故行进方向取 $-P'$。盘出螺线 $Q(t)=-P(t)$ 沿 $t$ 增大盘出，$\mathrm{d}Q/\mathrm{d}t = -P'(t)$，行进方向**同为** $u(t)$ —— 这一条使两段螺线可以统一处理。

## 3. 自由度分析

题设固定了螺距、调头空间、2:1 半径比和三处相切。在这些约束下 S 形曲线仍剩 **2 个自由度**。取两切点的极径 $(r_A, r_B)$ 作为设计变量，与 $(R_1, \alpha_1)$ 互为坐标变换：

给定 $(t_A, t_B)$ 与弧1 转向 $\sigma$，圆心为
$$O_1 = A + R_1 n_1,\quad n_1 = \sigma\,\mathrm{rot}_{90}(u_A);\qquad
O_2 = B + R_2 n_2,\quad n_2 = -\sigma\,\mathrm{rot}_{90}(u_B)$$
外切条件 $|O_2-O_1| = R_1+R_2$ 展开后是 $R_1$ 的一元二次方程，故 $R_1$、$\alpha_1$、$\alpha_2$ 全部由 $(t_A,t_B)$ 决定。这确认了自由度确实是 2。

**一个必须补上的判据：行进方向连续性。** 几何相切只保证半径向量垂直于螺线切向，不区分同向与反向。若用 `arccos` 算扫角、只验证相切，会得到一批"相切但龙头要倒着走"的伪解。故对 A、B、C 三处都要求方向内积 $\approx +1$：

$$\sigma\,\mathrm{rot}_{90}(A-O_1)/R_1 \cdot u_A \approx +1,\quad
-\sigma\,\mathrm{rot}_{90}(B-O_2)/R_2 \cdot u_B \approx +1$$

加上 $r_{\max} \le 4.5$（不出调头空间），构成几何可行性。

## 4. 复合路径的弧长参数化

以切点 A 为原点、行进方向为正，定义弧长坐标 $s$：

| 区间 | 所在段 |
|---|---|
| $s<0$ | 盘入螺线 |
| $0\le s\le L_1$ | 弧1 |
| $L_1 < s \le L$ | 弧2 |
| $s>L$ | 盘出螺线 |

螺线弧长 $\displaystyle \mathrm{arc}(t)=\tfrac12 b\left(t\sqrt{1+t^2}+\operatorname{arcsinh} t\right)$，反解用牛顿法（$\mathrm{d\,arc}/\mathrm{d}t = b\sqrt{1+t^2}$）。

龙头速度恒为 1 m/s 时 $s_{\text{head}} = t$（秒），弧长坐标与题目时间同刻度。

## 5. 关键修正：后继把手的定位不能取"向后第一个根"

定位后继把手要解 $|P(s) - P(s')| = L$。最初用"沿路径向后的第一个根"，这在螺线上没问题（根唯一），但**当圆弧半径小到板凳可横跨整段弧（$2R_2 <$ 弦长）时该判据不连续**：根成对生灭，"第一个根"发生跳变。

实测证据（$r_A=1.808$、$R_2 = 0.609$ m、体节弦长 1.65 m）：

- $s_{\text{head}}: 2.75 \to 2.80$ 时第 1 把手 $S$ 从 $-2.63$ 跳到 $-13.00$；
- 全程 54.9% 的采样点出现 $\mathrm{d}S_i/\mathrm{d}s_{\text{head}} < 0$，即把手**倒退**；
- 逐点穷举根集确认：$s_0=8$ 处有三个根 $\{1.52,\ 2.93,\ 6.30\}$，判据取了最靠近的那个，与前一步不在同一分支。

**正确判据是连续延拓**：队伍自远处盘入（全队在螺线上、根唯一）出发，每个把手的 $s'$ 沿同一分支连续变化，用上一步的解作牛顿初值即可锁定分支。

由此得到的映射 $\varphi_L: s \mapsto s'$ 是一条**固定的一维函数**，与时间、与队伍长度无关，同长度板凳共用一个 $\varphi$。本题只有两种弦长（龙头 2.86 m、体节 1.65 m），故离散化两条曲线即可查表加速，无须逐时刻推进整队。

## 6. 第三个可行性条件：可跟随性

对刚性杆 $|P_i - P_{i+1}| = L$ 求导得相邻把手速度比

$$\frac{v_{i+1}}{v_i} = \varphi'(S_i) = \frac{d\cdot u(S_i)}{d\cdot u(S_{i+1})},\qquad d = P(S_i)-P(S_{i+1})$$

$\varphi' \le 0$ 意味着后把手须倒退才能维持杆长，**队伍无法沿该路径整体前进**。这是几何相切之外的独立约束，也是本题的关键：

| $r_A$ | $R_1$ | $R_2$ | $L$ (m) | $\min\varphi'$ | 可跟随 |
|---|---|---|---|---|---|
| 4.5 | 3.005418 | 1.502709 | 13.621245 | $+0.5447$ | 是 |
| 4.0 | 2.672760 | 1.336380 | 12.053547 | $-0.7860$ | 否 |
| 3.5 | 2.340295 | 1.170147 | 10.486715 | $-0.7787$ | 否 |
| 3.0 | 2.008117 | 1.004059 | 8.921173 | $-0.7708$ | 否 |
| 2.5 | 1.676399 | 0.838199 | 7.357667 | $-0.7429$ | 否 |
| 2.0 | 1.345479 | 0.672739 | 5.797658 | $-8.8436$ | 否 |
| 1.8 | 1.213481 | 0.606740 | 5.175253 | $-14947.7$ | 否 |

沿对称族 $r_A=r_B$ 减小 $r_A$，$L$ 单调减小、可一直压到退化（曾得到 $L=1.42$ m 的解，弧2 只占 3.2% 弧长，实质是单段圆弧）。**说明"最短"必须由可跟随性定界，而非碰撞。**

延拓本身的可信度经四项检验：杆长残差 $\le 3\times10^{-14}$、$s'<s$ 全程成立、$\max|\Delta s'|$ 与步长同量级（无跳支）、$\varphi'$ 与 $\mathrm{diff}(s')/\mathrm{diff}(s)$ 一致率 100%。故 $\varphi'<0$ 是真实几何效应，不是数值假象。只有 2.86 m 的龙头板会触发它（体节在 $r_A\ge2.2$ 时 $\varphi'$ 始终为正），与问题 2/3 中"龙头板最长、最先出问题"的结论一致。

## 7. 优化结果

在三条约束（几何相切与不越界、碰撞、可跟随）下最小化 $L$，$r_A$、$r_B$ 独立取值：

| | 基准（题给 S 曲线） | **最优解** |
|---|---|---|
| $r_A$ (m) | 4.500000 | **4.279000** |
| $r_B$ (m) | 4.500000 | **4.479000** |
| $R_1$ (m) | 3.005418 | **2.860140** |
| $R_2$ (m) | 1.502709 | **1.430070** |
| $\alpha_1$ (rad) | 3.021487 | **2.512626** |
| $\alpha_2$ (rad) | 3.021487 | **3.254637** |
| 弧1 长 (m) | 9.080830 | 7.186463 |
| 弧2 长 (m) | 4.540415 | 4.654359 |
| **总长 $L$ (m)** | **13.621245** | **11.840822** |
| $\varphi'$ 范围 | $[0.5447,\ 1.5578]$ | $[0.3715,\ 2.1395]$ |

**结论：能调整圆弧使调头曲线变短。最短约 $L = 11.8408$ m，比题给基准 13.6212 m 缩短 1.7804 m（13.07%）。**

最优解不对称（$r_A \ne r_B$）—— 这正是"两条螺线中心对称但调头路径不必中心对称"这一自由度带来的收益：对称族在可跟随性临界点（$r_A \approx 4.2558$）只能取到 $L \approx 12.85$ m。

## 10. 小结

1. 题设约束下 S 形调头曲线有 2 个自由度，可取两切点极径 $(r_A, r_B)$。
2. 几何相切**不足以**定解，还需行进方向连续性（滤掉倒行伪解）与**可跟随性** $\varphi'>0$。
3. 后继把手不能用"向后第一个根"定位，小圆弧下该判据不连续；须用连续延拓。
4. 最短调头曲线 $L = 11.8408$ m，比题给基准缩短 13.07%；最优解不对称，收益来自"路径不必中心对称"这一自由度。
5. 全程无碰撞（最小间隙 0.2684 m），但 1 m/s 时最大把手速度已达 2.1587 m/s —— 这正是问题 5 要处理的。
