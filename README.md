# 2020年高教社杯数学建模A题 — 炉温曲线（参数辨识部分）

回焊炉炉温曲线的物理建模与参数辨识项目。基于2020年高教社杯全国大学生数学建模竞赛A题，建立PCB热响应模型并通过实验数据辨识换热参数。

## 模型架构

### 物理模型

**炉内环境温度场** Tf(x)：采用 Sigmoid 函数构造连续空间温度场，平滑参数 a=1.178 已固定。

**PCB热响应模型(模型二)**：平滑切换双换热系数模型
- 加热系数 kh = 0.01966939
- 冷却系数 kc = 0.00591111
- 切换平滑度 beta = 0.5（固定）
- ODE: dT/dt = k_eff(Tf-T)，k_eff = kc + (kh-kc)·σ(β·ΔT)

## 结果对比

| 模型 | 参数数 | RMSE (°C) | MAE (°C) | 加热MAE | 冷却MAE |
|------|:-----:|:---------:|:--------:|:-------:|:-------:|
| 模型一（单k） | 1 | 27.97 | 21.57 | 12.56 | 53.48 |
| **模型二（kh/kc）** | **2** | **5.74** | **3.98** | **2.33** | **9.87** |
