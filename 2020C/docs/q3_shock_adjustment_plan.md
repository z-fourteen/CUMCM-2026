# 第三问突发因素下的信贷调整策略

第三问以第二问对附件 2 中 302 家企业的授信结果为基础，进一步考虑突发因素对企业经营的影响，并在年度信贷总额 10000 万元约束下调整风险评价、贷款额度和贷款利率。

整体思路分为两层：

```text
基础模型：沿用第二问，得到正常经营情景下的基准风险和授信结果
策略升级：引入突发因素，调整关键经营指标，再重新评分和分配额度
```

## 一、基础模型

基础模型直接复用第二问的指标体系、评分规则和资金分配策略。第三问不重新建立机器学习模型，也不改变第二问的基础授信逻辑，而是在第二问结果上增加突发因素调整层。

### 1. 基准指标

第二问已经从附件 2 的进项发票、销项发票中构造了企业经营指标。第三问继续使用这些指标作为突发因素调整前的基准状态。

| 指标类别 | 指标 |
| --- | --- |
| 经营规模 | `有效销项金额`、`月均销项收入`、`毛利率` |
| 经营连续性 | `有效经营月份数`、`最长销项断档月数`、`销项收入波动系数` |
| 交易真实性 | `最大作废率`、`最大负数率`、`进销匹配差异` |
| 抗风险能力 | `客户数`、`供应商数`、`客户集中度HHI`、`供应商集中度HHI` |
| 信用评价 | `估计信用等级`、`信用得分`、`风险等级`、`是否一票否决`、`是否高风险池` |
| 授信策略 | `是否放贷`、`最终贷款额度_万元`、`建议贷款年利率`、`客户流失率` |

其中，`销项收入波动系数`由企业月度有效销项收入序列计算得到：

```text
销项收入波动系数 = 月度有效销项收入标准差 / 月度有效销项收入均值
```

该值越高，说明企业销售越不稳定，突发因素到来后发生收入波动或经营断档的风险越高。

### 2. 基准结果

第二问在年度信贷总额 10000 万元下的基准授信结果如下：

| 指标 | 基准结果 |
| --- | ---: |
| 实际分配额度 | 10000.00 万元 |
| 剩余额度 | 0.00 万元 |
| 放贷企业数 | 151 家 |
| 一票否决企业数 | 23 家 |
| 高风险池企业数 | 77 家 |
| 加权平均利率 | 7.8140% |

第三问的评估重点，是比较突发因素冲击前后这些结果的变化，例如风险等级是否上调、放贷企业是否减少、额度是否向低风险企业集中、加权平均利率是否上升等。

### 3. 基准授信规则

基础模型仍采用第二问的信用得分分级规则：

| 信用得分 | 风险等级 |
| ---: | --- |
| >= 80 | 低风险 |
| >= 65 且 < 80 | 较低风险 |
| >= 50 且 < 65 | 中风险 |
| < 50 | 高风险 |

贷款额度仍由信用得分和风险等级共同确定：

```text
初始建议额度 = 10 + 90 * 信用得分 / 100
```

| 风险等级 | 额度区间 |
| --- | ---: |
| 低风险 | 70 至 100 万元 |
| 较低风险 | 40 至 80 万元 |
| 中风险 | 10 至 50 万元 |
| 高风险 | 10 至 30 万元 |
| 高风险池 | 额度上限压缩至 30 万元 |
| 一票否决 | 0 万元 |

资金分配顺序为：

```text
风险等级优先 -> 非高风险池优先 -> 信用得分高优先
```

## 二、策略升级

策略升级部分用于回答第三问的核心要求：突发因素对不同行业、不同类别企业的影响不同，因此不能对所有企业采用相同的风险调整幅度。

升级后的流程为：

```text
识别突发因素
-> 按企业行业/类别确定基础冲击等级
-> 按企业脆弱性修正冲击幅度
-> 调整经营指标
-> 重新计算信用得分和风险等级
-> 调整额度、利率和放贷顺序
```

### 1. 行业分类的作用

行业分类只用于确定突发因素的基础冲击强度，不直接作为授信歧视条件。

例如疫情冲击下，医疗药品、食品民生类企业需求相对刚性，冲击较低；文娱广告、线下门店、装饰装修类企业受客流下降、订单减少影响更明显，冲击较高；制造、商贸、物流类企业通常受到中等冲击。

由于附件 2 没有直接给出行业字段，因此用企业名称关键词进行行业/类别代理识别。

| 行业/类别 | 关键词示例 | 疫情冲击等级 |
| --- | --- | --- |
| 医疗药品与健康服务 | 药房、药业、医疗、医药、诊所、健康 | 低 |
| 食品与基础民生 | 食品、粮油、农产品、生鲜、超市、便利 | 低 |
| 科技与线上服务 | 网络科技、软件、信息、技术服务、互联网 | 低至中 |
| 普通批发商贸 | 商贸、贸易、物资、供应链、五金、办公用品 | 中 |
| 制造与设备 | 机械、设备、电子、塑胶、材料、机电 | 中 |
| 物流运输 | 物流、运输、货运、配送 | 中 |
| 建筑与工程 | 建筑、工程、建材、园林、市政、消防 | 中至高 |
| 装饰装修与家居 | 装饰、装修、门窗、灯饰、家居、美居 | 高 |
| 文娱广告与线下服务 | 文化、传媒、广告、营销策划、体育、培训 | 高 |
| 可选消费与门店经营 | 服饰、童装、美容、花店、工艺品、个体经营 | 高 |

若企业名称无法明确归类，则默认采用中等冲击。

### 2. 突发因素设定

第三问以新冠疫情为主情景，因为题目中明确给出该示例。其他突发因素可作为扩展情景或敏感性分析。

| 突发因素 | 主要影响 | 主要作用指标 |
| --- | --- | --- |
| 新冠疫情 | 停工停产、客流下降、订单减少、回款变慢 | `有效销项金额`、`月均销项收入`、`有效经营月份数`、`最长销项断档月数`、`销项收入波动系数` |
| 自然灾害 | 经营中断、物流受阻、库存损失 | `有效经营月份数`、`最长销项断档月数`、`销项收入波动系数` |
| 供应链中断 | 原材料短缺、交付延迟、生产停滞 | `供应商集中度HHI`、`进销匹配差异`、`毛利率` |
| 市场需求骤降 | 销售收入下降、订单减少 | `有效销项金额`、`月均销项收入`、`客户集中度HHI` |
| 原材料或能源价格上涨 | 成本上升、利润压缩 | `毛利率`、`进销匹配差异` |
| 政策监管变化 | 行业整顿、环保限产、资质约束 | `有效经营月份数`、`最长销项断档月数`、`风险等级` |
| 利率或融资环境变化 | 客户流失率上升、融资成本增加 | `建议贷款年利率`、`客户流失率`、`是否放贷` |
| 主要客户或供应商违约 | 回款困难、采购中断 | `客户集中度HHI`、`供应商集中度HHI`、`销项收入波动系数` |

### 3. 冲击幅度确定

冲击幅度由两部分组成：

```text
实际冲击幅度 = 行业基础冲击幅度 * 企业脆弱性修正系数
```

行业基础冲击幅度体现突发因素对行业的平均影响。以疫情为例：

| 冲击等级 | 收入下降率 | 毛利率下降 | 波动系数上升率 | 经营月份减少 | 最长断档增加 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 低冲击 | 5% | 2 个百分点 | 10% | 0 月 | 0 月 |
| 中冲击 | 15% | 5 个百分点 | 25% | 1 月 | 1 月 |
| 高冲击 | 30% | 10 个百分点 | 50% | 2 月 | 2 月 |

企业脆弱性修正系数用于体现同一行业内不同企业的抗冲击能力差异：

| 脆弱性条件 | 放大幅度 |
| --- | ---: |
| `客户集中度HHI > 0.80` | +20% |
| `供应商集中度HHI > 0.80` | +20% |
| `销项收入波动系数 > 1.00` | +15% |
| `毛利率 < 5%` | +15% |
| `有效经营月份数 < 12` | +10% |
| `是否高风险池 = 是` | +10% |

```text
企业脆弱性修正系数 = 1 + 各项放大幅度之和
```

为避免惩罚过度，修正系数上限设为 1.60。

例如，某企业属于高冲击行业，基础收入下降率为 30%；同时客户集中度高、收入波动大，则：

```text
企业脆弱性修正系数 = 1 + 20% + 15% = 1.35
实际收入下降率 = 30% * 1.35 = 40.5%
```

### 4. 指标调整公式

设：

```text
s = 企业脆弱性修正系数
d_rev = 行业基础收入下降率
d_margin = 行业基础毛利率下降幅度
d_vol = 行业基础波动系数上升率
d_month = 行业基础经营月份减少数
```

实际冲击参数为：

```text
D_rev = min(d_rev * s, 0.60)
D_margin = min(d_margin * s, 0.20)
D_vol = min(d_vol * s, 1.00)
D_month = round(d_month * s)
```

调整后的主要指标为：

```text
调整后有效销项金额 = 原有效销项金额 * (1 - D_rev)

调整后月均销项收入 = 原月均销项收入 * (1 - D_rev)

调整后毛利率 = 原毛利率 - D_margin

调整后销项收入波动系数 = 原销项收入波动系数 * (1 + D_vol)

调整后有效经营月份数 = max(0, 原有效经营月份数 - D_month)

调整后最长销项断档月数 = 原最长销项断档月数 + D_month
```

供应链中断、需求骤降、原材料上涨等扩展情景，可进一步调整对应指标：

```text
调整后供应商集中度HHI = min(1, 原供应商集中度HHI * (1 + 0.10 * s))

调整后客户集中度HHI = min(1, 原客户集中度HHI * (1 + 0.10 * s))

调整后进销匹配差异 = 原进销匹配差异 * (1 + 0.10 * s)
```

### 5. 信贷策略调整

指标调整后，沿用第二问评分流程重新计算信用得分、风险等级、一票否决和高风险池。

在第二问高风险池规则基础上，第三问增加突发因素审慎条件：

- 疫情冲击下，高冲击行业且 `销项收入波动系数 > 1.5`
- 疫情冲击下，高冲击行业且 `有效经营月份数 < 12`

额度仍先按信用得分和风险等级计算，再根据冲击等级进行折减：

| 冲击等级 | 额度折减规则 |
| --- | --- |
| 低冲击 | 不额外折减 |
| 中冲击 | 冲击后额度乘以 90% |
| 高冲击 | 冲击后额度乘以 75% |
| 高冲击且进入高风险池 | 额度上限不超过 20 万元 |

若折减后额度低于 10 万元，则暂缓授信。

利率仍以风险等级对应区间为基础。若冲击后风险等级上升，则进入更高利率区间；若风险等级不变但属于中、高冲击行业，则在原候选利率区间中选择偏高的收益最优利率，以补偿风险溢价。

### 6. 评价指标

第三问采用冲击前后对比评价策略效果。

| 指标 | 含义 |
| --- | --- |
| 平均信用得分变化 | 衡量整体信用风险恶化程度 |
| 风险等级上调企业数 | 衡量风险迁移 |
| 新增高风险池企业数 | 衡量需审慎处理的企业增加 |
| 新增一票否决企业数 | 衡量严重风险企业增加 |
| 放贷企业数变化 | 衡量授信覆盖面变化 |
| 实际放贷金额和剩余额度 | 检验 10000 万元是否仍可在风控约束下投放 |
| 额度削减总额 | 衡量授信收缩程度 |
| 加权平均利率变化 | 衡量风险补偿变化 |
| 各风险等级放贷数量 | 检验资金是否向低风险企业集中 |

可进一步设置温和、基准、严重三种疫情强度进行敏感性测试：

| 情景 | 冲击系数 |
| --- | ---: |
| 温和疫情 | 基础冲击的 70% |
| 基准疫情 | 基础冲击的 100% |
| 严重疫情 | 基础冲击的 130% |

若在严重情景下，资金仍主要分配给低风险和较低风险企业，且高风险池企业额度明显压缩，则说明调整策略具有稳健性。

### 7. 加强策略

为体现突发因素下银行授信的审慎性，在原有策略升级基础上进一步加入两条保守规则：

1. **高冲击高风险池暂停授信**

   若企业同时满足“高冲击行业”和“进入高风险池”，则不再仅进行额度压缩，而是直接暂停授信。该规则用于处理受突发因素影响最明显、且自身经营稳定性较弱的企业，避免风险在高冲击行业内继续暴露。

2. **严重冲击情景下不强制用满额度**

   在严重冲击情景下，银行不再以用满 10000 万元年度信贷额度为目标，而是保留 10% 的风险准备额度。因此 severe 情景下最高实际投放额度设为：

```text
严重情景可投放额度 = 年度信贷总额 × 90%
```

   若年度信贷总额为 10000 万元，则严重情景下最多投放 9000 万元，剩余 1000 万元作为风险缓冲。这样可以避免在整体经营环境恶化时，为了追求额度使用率而被动向边际风险更高的企业投放资金。
