# 2024 CUMCM A题 · 板凳龙（问题一：盘入运动学 & 问题二：首次碰撞检测）

2024 年全国大学生数学建模竞赛 A 题完整求解。板凳龙共 223 节板凳（1 龙头 + 221 龙身 + 1 龙尾），以把手销接，共 **224 个把手中心** `P_0, …, P_223`。

* **问题一**：全部把手沿阿基米德螺线盘入的运动学（位置与速度）。
* **问题二**：考虑板凳实体（宽度 0.30 m 的矩形），检测非相邻板凳碰撞，求首次碰撞临界时刻 t\*。

## 问题简述

- 龙头前把手 `P_0` 从阿基米德螺线第 16 圈起点 `A = (8.8, 0)` 出发，以 **恒线速 1 m/s** 沿螺线顺时针向内盘入。
- 螺距 `p = 0.55 m`，螺线参数 `a = p/(2π)`，`r = aθ`。
- 相邻把手中心间距为**刚性弦长**：龙头 `L_1 = 3.41 − 2×0.275 = 2.86 m`，龙身/龙尾 `L = 2.20 − 2×0.275 = 1.65 m`。
- 需给出 `t = 0, 1, …, 300 s` 共 301 个时刻全部把手的 x、y 坐标与速度大小，保留 6 位小数。

## 模型要点

1. **龙头运动**：由弧长原函数 `F(θ) = ½[θ√(1+θ²) + asinh θ]`，解非线性方程
   `a[F(32π) − F(θ₀(t))] = t` 得到 `θ₀(t)`（brentq 求根）。
2. **龙身递推**：相邻把手满足**欧氏弦长**约束（而非弧长约束）
   `a²[θᵢ² + θᵢ₋₁² − 2θᵢθᵢ₋₁cos(θᵢ−θᵢ₋₁)] = Lᵢ²`，
   取 `θᵢ > θᵢ₋₁` 的**最近正向根**，逐节递推 `θ₀ → θ₁ → … → θ₂₂₃`。
3. **速度**：由刚性杆约束 `dᵢ·(Vᵢ − Vᵢ₋₁) = 0`（`Vᵢ = vᵢTᵢ`，`Tᵢ` 为盘入方向单位切向量）解析递推
   `vᵢ = vᵢ₋₁·(dᵢ·Tᵢ₋₁)/(dᵢ·Tᵢ)`，`v₀ = 1`；并用隐函数微分法与中心差分交叉验证。

## 问题二：板凳实体几何与首次碰撞检测

舞龙队沿同一阿基米德螺线继续盘入。考虑板凳为**宽度 0.30 m 的矩形**（孔中心距板端 0.275 m，故矩形半长 = 把手间距/2 + 0.275），对全部**非相邻**板凳对（编号差 ≥ 2，共 24531 对）做碰撞检测，求首次碰撞临界时刻 t\*。

### 模型要点

1. **分离轴定理 (SAT)**：两矩形相交当且仅当在 4 个分离轴（两矩形各自的轴向 u、法向 n）上的投影区间均不分离；相切亦判碰撞。
2. **间隙函数**：重叠/接触时取 0，否则取两矩形之间最小"顶点-边"距离（凸多边形最小距离必由顶点-边/顶点-顶点取到）。
3. **首次碰撞搜索**：全局最小间隙 g(t) 连续，粗网格定位 `g≤0` 区间后按 `g>0/g==0` 指示函数二分，收敛到首次穿越点（精度 1e-9 s）。
4. **化简**：经证明，首次碰撞必由"前两节（龙头、第 1 节龙身）之一"与后方某非相邻节产生，故候选对由全部 24531 对化简为 441 对（`(0,j) j≥2` 与 `(1,j) j≥3`）；以全量搜索作对照，两者结果完全一致。

### 关键结果

| 量 | 值 |
|---|---|
| **首次碰撞临界时刻 t\*** | **412.473838 s** |
| 碰撞节 | **龙头（P₀–P₁）× 第8节龙身（P₈–P₉）** |
| 接触点 | (1.474395, 2.110665) m，接触残差 1.0e-11 m |
| t\* 时龙头 | θ=26.1465 rad, r=2.2887 m, (1.209931, 1.942784) m, v=1.000000 m/s |

物理图像：龙头长板（3.41 m）位于最内圈，盘入时其前端角点扫过下一内圈，与第 8 节龙身首次接触；此前龙头板依次"擦肩"第 10、9 节（最近处间隙 0.0255 m、0.0030 m）均未接触。
